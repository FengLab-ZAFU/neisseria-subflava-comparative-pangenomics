# Retrieval and source curation

The frozen retrieval snapshot is 1 October 2026. The genus query was Neisseria, NCBI TaxID 482, current assembly versions. The original CLI form was `datasets summary genome taxon 482 --assembly-version current --as-json-lines`. The actual archived retrieval scripts include paginated NCBI Datasets v2 API requests and resumable date-window retrieval, because a single CLI response was incomplete.

The API request uses `POST https://api.ncbi.nlm.nih.gov/datasets/v2/genome/dataset_report` with `taxons=["482"]` and `filters.assembly_version="current"`. N. gonorrhoeae (TaxID 485) and N. meningitidis (TaxID 487) subtrees and atypical assemblies are filtered locally. The source code for retrieval, tiering, downloading, bidirectional ANI and SNP calling is under `code/project/scripts/revision_20261001/`. Source-role/participant corrections and complete-linkage dereplication are under `code/project/results_revision_20261010_sourcefix_v7/delivery/scripts/`.

A live query today is not an exact replay of the frozen snapshot. Use `metadata/screening1303.tsv`, the frozen assembly versions and the retained source/identity ledgers for the published cohort. Laboratory derivatives, MAGs, source-role conflicts and QC failures are resolved before choosing dereplicated representatives. Source-identity duplicates and participant clones are distinct decisions. The participant clone rule uses complete linkage at 20 unmasked whole-genome SNPs with sufficient shared callable sequence; unresolved distances do not permit a merge. The original code also records 5/10/50-SNP group-count sensitivities.

Some upstream scripts expect full FASTA/annotation files, tool databases and earlier raw ANI/SNP intermediates from the original project. The repository includes the actual upstream code and the corrected source/unit/cohort ledgers; full upstream reconstruction requires the additional files listed in REPRODUCIBILITY.md. Raw genomes can be downloaded by their versioned accessions. The original genus JSON pages and some corrected raw pairwise-SNP/ANI files are not included in this repository.
