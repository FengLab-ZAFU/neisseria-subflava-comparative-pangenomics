Run `python code/reproduce.py run figure2` to check and export the supplied iTOL package to `analysis_outputs/figure2_itol/`. To repeat ML inference from the supplied alignment, use IQ-TREE 2.4.0 in a separate output directory:

```bash
iqtree2 -s /absolute/prepared/project/revision2/phylogeny/aln157_unfiltered.fasta -m GTR+F+I+R4 -alrt 1000 -B 1000 -seed 20261015 -keep-ident -T AUTO --prefix rerun157
```

The original command used 160 threads; the thread count above is adapted for the rerun host. The original command and environment are recorded in `main157.log`. A new ML run is not part of release validation.
